Free API

The same check is available as a free JSON API. No key, no sign-up. It takes 1 to 50 messages of up to 2,000 characters.

  • POST /api/predict returns a verdict, a score, the likely type and the words behind it.
  • GET /api/health reports the model and a built-in self-check.
